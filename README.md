# Java Basics

Beginner Java programs covering syntax fundamentals, following CodeWithHarry's Java course.

## Files

| File | Concept |
|---|---|
| `CHW_04_literal.java` | Java literals — byte, char, float, String |
| `CHW_05_takinginput.java` | Taking user input using the `Scanner` class |
| `ExerciseOne.java` | Program to calculate a student's mark percentage from 5 subjects, taken as keyboard input |

## Concepts covered
- Java literals and data types (`byte`, `char`, `float`, `String`)
- `Scanner` class for reading keyboard input (`nextInt()`, etc.)
- Basic arithmetic and type casting
- Integer vs floating-point division (and why `5` vs `5.0f` matters for decimal precision)

## Coming from C
First Java programs after completing C fundamentals (pointers, arrays, strings, structures, file I/O, dynamic memory allocation). Java's OOP structure and Scanner-based input are the main syntax differences from C so far.

## How to run
```bash
javac <filename>.java
java <classname>
```
